# YaninaCattadori

YaninaCattadori es la estructura inicial de un e-commerce para un atelier de moda circular, arreglos de ropa, transformacion de prendas y diseno de indumentaria. Esta pre-entrega contiene la base del proyecto, una pantalla inicial limpia y la carpeta de componentes para organizar las proximas entregas.

## Tecnologias utilizadas

- React
- JavaScript
- Vite
- HTML
- CSS

## Instalacion y ejecucion

Para instalar las dependencias:

```bash
npm install
```

Para ejecutar la aplicacion en modo desarrollo:

```bash
npm run dev
```

Luego abrir en el navegador la URL local que indique Vite, por ejemplo:

```text
http://localhost:5173/
```
